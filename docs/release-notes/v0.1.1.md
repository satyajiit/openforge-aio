# OpenForge v0.1.1

Patch release recovering the LEGO Batman: Legacy of the Dark Knight trainer on the post-update game build, with update-resilient discovery and a code-modification-free game-thread executor.

## Highlights
- The trainer works again on the current LEGO Batman: LotDK build — reflection self-heals through game updates instead of breaking on every patch.
- UFunction-backed features (unlock all skills / fast-travel / outfits, fly, NPC dance, teleport-to-waypoint) run on the game thread via a hardware-breakpoint executor that modifies no game code.

## Fixes
- **Self-healing GUObjectArray discovery.** The game update relocated `GUObjectArray` (+0x4000), so the hardcoded address read a zeroed header and walked 0 live objects. Reflection now self-heals via a structural `FChunkedFixedUObjectArray` fingerprint scan, so it adapts to the live address and survives updates / store variants.
- **Game-thread UFunction executor.** UFunction dispatch (`ProcessEvent`) crashed the game when called off the game thread, and the inline-hook path hung on the new prologue. Replaced with a hardware-breakpoint rendezvous (debug registers + a vectored exception handler) that runs the dispatch on the game thread with no code modification. The game-thread id is cached so bulk grants and per-frame features stay fast.
- **Reflection crash-safety.** Dropped the stale instance-address cache and validate dereference-chain objects are live before writing through them, so freeze writes can't corrupt reallocated objects.

## What's new (developer tooling)
- `discover ue5-locate` — external-RPM signature discovery with RVA-drift reporting.
- `discover ue5-soak` — sustained-load reflection reproduction harness.
- `discover/re/dump_stack.py` — minidump faulting-thread stack reader (no debugger required).

## Known issues
- `FName::ToString` and `ProcessEvent` are still resolved from build-specific RVAs (correct on this build; they would need the same auto-discovery as `GUObjectArray` for other stores / future updates).
- Live "X / Y unlocked" status is not recomputed on the automatic attach sweep (it would require per-tag game-thread calls); it refreshes after a grant.

## Install
- Extract `openforge.exe` and `batman_lod_dll.dll` into the same folder and run `openforge.exe` as administrator, or grab the `openforge-v0.1.1-windows-x64.zip` bundle.

Requires Windows 10+. Single-player offline scope only. No anti-cheat-protected games.
